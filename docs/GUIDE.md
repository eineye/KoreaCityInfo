Korea City Info

1. 외국인들에게 한국에 대한 정보를 알리는 목적
2. 주요 서비스는 한국내 지자체들의 다양한 정보를 알림
3. 주요 언어 : 영어(다국어 지원 선택 가능하도록)
4. 메일 서비스 플랫폼 : 앱(안드로이드 우선/ 추후 아이폰서비스 지원)
5. 웹서비스도 지원 (호스팅 주소 보유) : 웹에서 관리자 모드 지원되어야 함.

참조 url :  https://koreacity.pages.dev/

지원 세부내용

1. 앱에서는 메인 페이지에 한반도 지도와 하단에 필요한 배너 배치
2. 화면 구성 상 메인 메뉴는 햄버거 메뉴 구현
3. 상세 진행사항

\*한반도 지도를 클릭하면 해당지역 지자체별 인터넷주소와 배너(해당지자체 소개)가 뜨고...
\*Mayor's Greetings를 클릭하면 소개하려는 지자체 시장들의 소개 배너들이 뜨고....
\*Festivals 클릭하면 소개하려는 지자체들의 축제관련 배너들이 뜨고....
\*Investment 클릭하면 소개하려는 지자체들의 투자유치관련 배너들이 뜨고....
\*U-TUBE 클릭하면 내 유튜브(koreacity)에 소개한 지자체들관련 내용들이 뜨고....(내 유튜브 계정과 연결)
\*FACEBOOK클릭하면 내 페이스북(koreacity)에 소개한 지자체들관련 내용들이 뜨고....(내 페이스뷱 계정과 연결)
\*X클릭하면 내 X (koreacity)에 소개한 지자체들관련 내용들이 뜨고....(내 X 계정과 연결)

4. 관리자 모드에서 위 상세내용을 모두 수정.삭제.업데이트.url연결 등 모든 관리내용 포함
5. 회원가입은 테스트 버젼에서는 임시 아이디/비번 모드로 구성하고 추후 플랫폼 연결 가입 또는 별도 가입 유도
6. 지도 서비스는 구글.네이버 등 플랫폼 회사의 맵 서비스를 이용하지 않고 (다양한 맵서비스 필요 없음) , 참고 페이지 처럼
한국 지도에서의 행정구역 표현 후 클릭 이벤트로 상세내용 표시하는 방법 진행.
7. 지도구성 :
* 광역자치단체는 총 16개 > 기초자치단체 227 개 지역으로 이동하면 세부내용 노출 방법
